# Deploy to GitHub Pages

1. Push the contents of this `Code/` folder to a GitHub repository root.
2. Open **Settings → Pages** in that repository.
3. Select **Deploy from a branch**, choose the default branch and **/(root)** folder, then save.
4. Open `https://<your-github-username>.github.io/<repository-name>/#/home`.

This app uses relative paths, an empty `.nojekyll`, root `404.html`, and hash routing. No build command is required.
