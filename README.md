# Tatkal Booking Clarity (Demo)

An independent hackathon prototype showing a clearer Tatkal payment-to-ticket status journey. All payment, booking and passenger data is synthetic.

## Run locally

Do not open with `file://`. From inside `Code/`, run `python -m http.server 8080`, then open `http://localhost:8080/#/home`.

The prototype uses hash routes and local browser storage, so routes can be refreshed and the current demo outcome is retained.
