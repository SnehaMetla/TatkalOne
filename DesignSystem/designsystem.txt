# Tatkal Booking Clarity Design System

## Implemented prototype system (27 Aug 2026)

The independent hackathon prototype uses a trust-focused navy, orange and white transactional interface, without official logos or claims. Body copy is 16px minimum, controls are at least 44px high, and every semantic state has both a label and a recognised marker: ✓ confirmed, R RAC, W waiting list, × failed, and ○ pending.

- **Tokens:** `--navy #163b8c`, `--orange #fb792b`, `--green #087f3e`, `--yellow #b66b00`, `--wait #bd5b16`, `--red #ba1a1a`; 4px spacing increments; 4–8px radii.
- **Layout:** a centred 1200px maximum content area; two columns on desktop, one column on tablet/mobile. The four-stage timeline switches from horizontal to vertical on small screens.
- **Core components:** persistent dismissible demo banner, top navigation, journey context card, scenario selector, mock payment options, four-stage timeline, action card, money-update card, error/recovery guidance and non-blocking toast.
- **Behaviour:** selection and current flow state persist in localStorage. All payment, identity and booking information is visibly synthetic and all outcomes are supplied by local mock data.

## Prototype implementation note (26 Aug 2026)

The independent Tatkal-status prototype applies the existing IRCTC navy/orange/white language to a clarity-first transactional journey. It uses white bordered cards, 4–8px radii, a 4px spacing scale, system font fallback for offline resilience, and orange primary actions. Booking states always pair labels and symbols with semantic colour: green confirmed, yellow RAC, orange waiting list, and red failure/pending. The four-stage status timeline is the core reusable component and consistently separates payment, booking, ticket and seat allotment. A high-contrast demo disclosure is persistent at the app top.

Extracted from the live site (`https://www.irctc.co.in/nget/train-search`) via computed-style inspection, cross-checked against the homepage reference screenshot. Built on **Angular + PrimeNG** (icon classes `primeicons`, `.p-inputtext` present) with **FontAwesome** and **Bootstrap Glyphicons** for legacy icon sets.

## 2. Typography

**Primary typeface:** `Quicksand` (loaded as `"Body, Quicksand, sans-serif"`)
**Fallback stack:** `"Open Sans", "Helvetica Neue", sans-serif` and `Arial, sans-serif`
**Secondary/legacy stack:** `Montserrat, Verdana`, `"Segoe UI", Arial, sans-serif` (used in older widget fragments)
**Icon fonts:** `FontAwesome`, `Glyphicons Halflings`, `primeicons`

Base body size: **14px**, color `#000000`/`#333333`.

| Level | Size | Weight | Line-height | Notes |
|---|---|---|---|---|
| H1 | 24px | 700 | 26.4px (1.1) | Section titles |
| H2 | 34px | 600 | 37.4px (1.1) | Hero / large display headings |
| H3 | 24px | 700 | 26.4px (1.1) | Card / block titles |
| Body | 14px | 400 | ~1.4 | Default paragraph |
| Small / label | 12–13px | 400–600 | — | Form labels, nav links |
| Button | 14px | 600–700 | — | All CTAs |

Observed font-size scale in the wild: `10px, 10.5px, 12px, 13px, 13.5px, 14px, 15px, 16px, 17.5px, 18px, 20px, 21px, 24px, 25px, 30px, 32px, 34px, 50px` — effectively a fluid/non-strict scale, but **12 / 14 / 16 / 20 / 24 / 34px** are the workhorse sizes.

### Booking Widget (hero card)
- Floating white card overlapping the hero banner image, `border-radius` on the card ~8px, subtle drop shadow.
- Internal tab bar ("PNR STATUS" / "CHARTS/VACANCY") uses deep blue `#213D77` as the active-tab indicator/background, white icon+text.
- Fields: From / To (swap icon between them), Date picker, Class dropdown, Quota dropdown, two checkboxes row.
- CTA button (orange, full-width-ish) anchors the bottom of the card.

### Navigation / Header
- Slim **utility bar** (white bg): live clock, accessibility text-size controls (A⁻ / A / A⁺), language switcher, "हिंदी" link — all small caps ~12px.
- **Primary nav** (dark blue gradient `#163B8C`→`#213D77`): white uppercase-style menu items (Home, Trains, Meals, Loyalty, E-Wallet, Alerts, Other Services, Contact Us) at 13–14px weight 600, with "LOGIN/REGISTER" and "TRAINS" items visually emphasized (red/bold accents).
- Logo lockup: circular railway emblem (left) + wordmark "IRCTC" in navy `#2E3192` (right), plus a right-aligned circular monogram badge.

### Info / Promo Banner
Light blue tint background (`#EEF5FF`) full-width strip beneath the header, dark navy text, blue pill CTA button ("Explore beta now"), dismiss "×" icon at 24px `#444444`.

### Cards (service tiles, holiday packages)
- **Icon tiles** ("FLIGHTS", "HOTELS", "RAIL DRISHTI", etc.): circular outlined icon (grey stroke) above a bold uppercase label, arranged in a responsive grid, no visible card border/shadow — pure icon + label pattern.
- **Content cards** (Holidays section: "Maharajas' Express", "International Packages", etc.): image (top, full-bleed, ~4:3), bold title (H4-ish, ~16–18px/700), 3–4 line muted description (`#535D66`, 13–14px), "Read More →" link in brand blue, laid out in a 3-column responsive grid on white background.

### Footer
```
background: #2C215D
color: #FFFFFF
```
- Top row: circular social icons in brand colors (Facebook, WhatsApp, YouTube, Instagram, LinkedIn, Telegram, Pinterest, Tumblr, Snapchat, Twitter/X) on a magenta/purple gradient strip.

## 6. Layout & Grid

- Max content width: full-bleed sections with an inner constrained container (~1200–1280px) for text/card grids.
- Hero: full-width background image/banner with an overlapping floating booking card (asymmetric two-column: ~35% widget / 65% imagery on desktop).
- Service-tile grid: 5 columns desktop → collapses to 3–4 on tablet → 2 on mobile.
- Content card grid: 3 columns desktop → 1 column mobile.
- Responsive breakpoint hint from meta viewport: `width=device-width, initial-scale=1` (standard mobile-first responsive design; no fixed-width legacy layout).

## 7. Iconography

- **FontAwesome** — general UI icons (search, location, close, social).
- **Glyphicons Halflings** — legacy Bootstrap-era icons (calendar, swap arrows).

- Style: mostly line/stroke icons inside thin circular outlines (service tiles) or solid glyphs inline with text (nav, forms).

---

## 8. Voice / Visual Tone

- Government/PSU-grade trust signals: national emblem, tricolor-adjacent navy/orange/white palette, security certification badges in the footer.
- Dense, utility-first information architecture (many nav items, small type, high link density) typical of transactional government portals — prioritizes function and coverage over whitespace.
- Photography: high-saturation train/travel imagery (Vande Bharat exterior shots, scenic holiday destinations) used as emotional/aspirational accents against an otherwise information-dense, low-ornamentation UI.
